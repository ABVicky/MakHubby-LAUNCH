# MakHubby — Official Launch Experience Presentation

> **An interactive, cinematic, high-contrast storytelling website engineered for the official launch event of MakHubby (powered by Manikarnika Technologies).**

---

## 🌟 Highlights

- **20-Scene Cinematic Narrative:** From the initial idea on `01.01.2026` to `243 Days`, `4,374 Dev Hours`, `73,500+ Lines of Source Code`, and expanding across universities throughout India.
- **Auditorium Projector & Board Optimized:**
  - Ultra high-contrast colors and crisp typography designed for large projection screens and distance visibility.
  - Persistent High-Contrast Top Dual-Brand Header (`MakHubby` + `Manikarnika Technologies`).
  - **Stage Laser Pointer Mode (`L` key)**.
  - **Stage Blackout Mode (`B` key)** for speaker focus.
  - Auto-hiding HUD and cursor when idle.
- **Pure Vanilla Web Architecture:** Zero external bundlers or node framework dependencies. Pure HTML5, CSS3, and JavaScript.
- **Interactive Visuals & Procedural Web Audio:**
  - Procedural Web Audio synthesizer generating bass impacts, risers, and glitch bursts natively.
  - Ambient particle constellation background.
  - Interactive India Map vector canvas with university network laser beams.

## 🚀 Quick Start / Local Running

You can simply open `index.html` directly in any web browser, or start a local HTTP server:

```bash
# Using Python
python3 -m http.server 8000

# Open in browser:
# http://localhost:8000
```

## 🎮 Stage Keyboard Controls & Remote Clicker Shortcuts

| Key / Action | Function |
| :--- | :--- |
| **`Space` / `→` / `Clicker Next`** | Advance to Next Scene |
| **`←` / `Clicker Prev`** | Return to Previous Scene |
| **`F` / `F5`** | Fullscreen 16:9 Stage Mode |
| **`L`** | Toggle Virtual Stage Laser Pointer |
| **`B` / `.`** | Stage Blackout (Blank Screen) |
| **`M`** | Toggle Procedural Web Audio SFX |
| **`P`** | Open Scene Navigator Drawer (`01 - 20`) |
| **`?` / `H`** | Keyboard Shortcuts Help |
| **`Home` / `End`** | First / Last Scene |
